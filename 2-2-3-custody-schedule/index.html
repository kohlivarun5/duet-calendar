What is a 2-2-3 custody schedule?

The 2-2-3 rotation is a common 50/50 parenting schedule because each parent sees the child every few days. It can work well for younger children or families that want frequent contact with both homes.

Pros

  • Balanced parenting time across a two-week cycle.
  • No parent goes a full week without parenting time.
  • Weekends alternate in a predictable way.

Watchouts

  • More handoffs than week-on/week-off schedules.
  • Activities and school supplies need a clear shared calendar.
  • Holiday exceptions should be planned separately from the base rotation.
